# Chorvadorim.uz

O'zbekiston fermerlari uchun sun'iy intellekt asosida ishlaydigan raqamli chorvachilik boshqaruv platformasi.

🔗 **Sayt:** [chorvadorim.uz](https://chorvadorim.uz)
🤖 **Telegram bot:** [@chorvadorim_bot](https://t.me/chorvadorim_bot)

> **Eslatma:** Bu repositoriyada loyihaning to'liq kod bazasi emas, balki asosiy texnik yechimlarni namoyish etuvchi tanlangan namunaviy fayllar joylashtirilgan.

## Loyiha haqida

Chorvadorim.uz fermerlarga chorva mollarini, moliyasini va sog'lig'ini bitta joydan, AI yordami bilan boshqarish imkonini beradi.

## Asosiy funksiyalar

- 🤖 **AI Chat yordamchisi** — GPT-4o-mini asosida real vaqtda maslahat
- 📸 **Vizual tahlil** — hayvon rasmini yuklab, holatini AI orqali baholash
- 💬 **Telegram bot** — hisob bog'lash, hayvon qidirish, bank monitoring xabarnomalari
- 📊 **Moliyaviy kuzatuv** — xarajat, daromad va foyda real vaqtda hisoblanadi
- 💉 **Vaksinatsiya eslatmalari** — aqlli jadval asosida avtomatik xabarnomalar
- 🌐 **Uch tilli interfeys** — o'zbek (lotin/kirill) va rus tillarida
- 🌓 **Dark/Light rejim**

## Texnologik stack

| Qatlam | Texnologiya |
|---|---|
| Backend | Laravel 12 (PHP 8.2) |
| Ma'lumotlar bazasi | MySQL |
| AI Model | OpenAI GPT-4o-mini |
| Bot integratsiyasi | Telegram Bot API |
| Frontend | Blade, Tailwind CSS |

## Xavfsizlik

- Production muhitda `APP_DEBUG=false`
- So'rovlar chastotasi cheklangan (rate limiting)
- Telegram webhook maxfiy secret token orqali himoyalangan
- Barcha maxfiy ma'lumotlar (`.env`) ochiq kodga kiritilmagan

## Status

Loyiha soft-launch bosqichida — real fermerlar bilan sinovdan o'tmoqda. Bozorda ishonch qozonish maqsadida monetizatsiya hozircha kiritilmagan.
